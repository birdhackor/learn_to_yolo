# 從一個小 CNN，走到你看得懂的 YOLO

我們先用一個小 CNN 回答「整張圖是哪一類」。CNN（Convolutional Neural Network，卷積神經網路）是處理圖片常用的神經網路。再用 ResNet（殘差網路）的捷徑連接，理解網路如何加深：捷徑連接讓輸入走旁路跳過幾層，再加回後面的結果，使很深的網路也比較容易訓練。接著學會同時回答「圖裡有哪些物件，各自在什麼位置」，這種任務叫物件偵測。

YOLO（You Only Look Once，「只看一次」）是一系列物件偵測模型：整張圖只送進網路一次，就同時輸出所有框與類別。本教材的主角是 **MiniYOLO**：為了理解物件偵測而做的小型模型，用 PyTorch（Python 的深度學習函式庫）寫成。它從第 5 章開始逐步成形，到第 7 章成為能用圖片訓練、推論與評估的偵測器。沿途每次只引入一個主要變化，看看它解決什麼問題、帶來什麼好處，又增加什麼成本。

**開始前需要會什麼？**

- **必要：**會基本 Python（變數、if／for、函式、list 與 dict），也看得懂 class 的寫法（本書的模型都寫成 class；這是 Python 的寫法，和物件的「類別」是兩回事）。還不會的話，可以先讀 [Python 官方教學的繁體中文版](https://docs.python.org/zh-tw/3/tutorial/)第 3–5 章與第 9 章：前三章涵蓋變數、if／for、函式、list 與 dict，第 9 章介紹 class；第 0 章前半的手算只用到四則運算與平方，不必寫程式。
- **有了比較輕鬆：**照著範例跑過一次 PyTorch，聽過神經網路與卷積的概念。第 0 章從一個參數的手算講起，第 1 章說明卷積。
- **數學：**高中程度的函數、對數、向量與矩陣乘法即可。導數（變化率）與連鎖律，第 0 章會用數字例子從頭說明。

## 這裡怎麼學

從第一節（第 0 章的暖身）依序讀：**超短暖身 → 小 CNN → ResNet → 單張圖片的物件偵測 → YOLO 的演化 → 結業任務、影片與部署**。部署是把訓練好的模型匯出，交給其他程式或裝置實際使用。已有基礎時，可先看[完整閱讀路線](learning-path.md)，再看各節開頭寫的前置，決定從哪一節開始。

## 先看一個偵測的小問題

假設圖片裡有一個物件（這裡用紅色矩形代表），我們事先用框標出它的位置。這種事先由人標好的正確答案叫「標註」（annotation），後面的課程也常叫它 GT（ground truth，真值）或真值框；下圖的紅框是標註，不是模型的預測。

一張圖可能有好幾個物件，所以模型不只輸出一個框。第 7 章的 MiniYOLO 一次看整張圖，再把輸出排成 4×4 格：每一格對應圖上的一小塊區域，各輸出一組數字（這裡有沒有物件、框在哪、是哪一類），共 16 組；每一組對應一個「輸出位置」（第 5 章起也叫 slot 或候選）。訓練時要先決定哪個輸出位置要學這個框；沒有分到框的位置，則學「這裡沒有物件」。第 7 章的規則是讓**物件中心所在的格子負責預測**。先用下面的示意圖看懂這個規則。

![64×64 圖片中，紅框左上角為 (8,12)、右下角為 (24,28)，中心黑點 (16,20) 落在藍色虛線的負責格：索引列 1、欄 1，從 1 數起是第 2 列、第 2 欄](assets/diagrams/object-journey.svg){ width="400" }

座標寫成 `(x,y)`，從圖片左上角 `(0,0)` 開始，x 向右、y 向下，單位是畫素（pixel）。紅框的中心是左上角與右下角的平均：x=(8+24)÷2=16，y=(12+28)÷2=20，也就是 `(16,20)`。圖片寬、高都是 64，分成 4×4 格，每格寬、高就是 64÷4=16 畫素。要找中心落在哪一格，就把座標除以 16，再捨去小數：

- 欄（直的一排）看 x：16÷16=1。
- 列（橫的一排）看 y：20÷16=1.25，捨去小數得 1。

這兩個 1 就是程式用的索引（index：從 0 起算的編號，第一個是 0）：中心在 `(列=1,欄=1)` 這一格，也就是圖中藍色虛線的格子。圖上方與右側的紫色字標的就是索引；圖例的「第 2 列、第 2 欄」則是從 1 數起的說法。下面都用索引稱呼格子，例如「欄 1」指索引為 1 的那一欄。注意索引先寫列（由 y 決定）、再寫欄（由 x 決定），順序和座標 `(x,y)` 相反。例如中心若在 `(40,20)`，40÷16=2.5、20÷16=1.25，捨去小數後索引是 `(列=1,欄=2)`。

中心的 x 恰好在分界線 16 上，圖中的黑點就壓在這條線上。照「除以 16 再捨去小數」，16÷16 剛好是 1，所以它歸欄 1，也就是右側那一格（欄 1 涵蓋 16≤x<32）。同理，y 剛好壓在橫線上時，會歸下方那一格。框本身可以跨過幾個格子（這個框就跨了 4 格），負責格子仍由中心決定。模型算一格的數字時，也會用到這塊區域周圍的畫素，所以負責格預測的框可以超出這一格。

不必現在記住這組座標。之後的[訓練目標（target）](lessons/07-targets.md)會用同一個例子，逐步把標註轉成模型要學的數值。

偵測還有三件需要分清楚的事，後面會分節實作：

1. **訓練：**把圖片交給模型，用已知的標註算出 loss（損失：表示預測離答案多遠的一個數，越小越好），再更新參數，讓模型學會找物件。
2. **推論：**把新圖片交給訓練好的模型，取得預測框與類別；這時不需要答案（標註）。每一格都會輸出一個框，並附一個 0 到 1 之間的分數：分數越高，表示模型越相信那裡有物件、而且是它預測的那一類。分數太低的先丟掉。訓練好的模型也不完美：相鄰格子看到的畫面很接近，可能對同一個物件給出位置很像、分數也不低的框。所以最後用 NMS（Non-Maximum Suppression，非極大值抑制）整理：在同一類的框裡，留下分數最高的那個，刪掉和它重疊超過門檻的其他框；剩下的框再重複這個步驟。重疊程度用第 4 章的 IoU（交併比）衡量。
3. **評估：**用有標註、未參與訓練的圖片，對照預測與答案，檢查模型找對了多少。這時不更新參數。一定要用沒參與訓練的圖片，是因為模型可能只是記住了訓練圖片的答案；換成它沒看過的圖片，才知道它是不是真的學會。

有了這條基本管線（從輸入圖片、訓練、推論到評估，接好的一整串步驟）之後，再逐步研究各個 YOLO 系列怎麼改進這條管線，從早期版本一路到 YOLOv12、YOLO26。每一節都會說明借用了哪個機制、做了哪些簡化。YOLO 由不同團隊發展，名稱裡的數字由各團隊各自命名，不是同一個團隊依序推出的編號；版本號也不等於適合所有任務的排名。

## 電腦需求與驗證範圍

- **電腦需求：**各節實驗都只用 CPU；資料由程式自己產生，不必下載資料集。影片與部署章另有工具需求，各節會列出。
- **驗證方式：**你會先用已知答案的小例子檢查座標、框與計算，再用 CPU 確認模型能產生預測、計算 loss、更新參數。
- **已確認：**在程式畫的彩色矩形（顏色就代表類別）這種刻意簡化的題目上，短訓練（幾十到 1600 步）顯示小模型有能力學會。各章結果不一，例如 3.3 節沒有捷徑的 plain 網路就沒學會；有幾個實驗只看訓練圖，只能說明模型記得訓練圖多少。
- **做不到：**這些模型不會直接認得照片裡的貓或車；想偵測真實物件，要用有框標註的真實照片重新訓練，標註可以自己做，也可以用授權允許的公開資料集（第 8 章示範資料格式與流程）。
- **沒有驗證：**模型在真實照片上的偵測效果（包括用自己的資料重新訓練之後）、用真實資料長時間訓練，以及在真實資料上用相同訓練步數比較各機制的效果；也沒有正式的速度測試。各節 notebook 沒有在 Google Colab 上實際執行過，每節的執行紀錄都是在 Colab 以外的電腦上用 CPU 跑出的。也沒有請真人學生實際用本教材學習、測量學習效果。

??? note "技術細節：L4、checkpoint 與 TensorRT 的實測"

    GPU 上的實測只有兩項，是教材另外做的工程檢查；你跑各節實驗都不需要 GPU，第 20 章的 Colab 範例也只用 CPU。兩項都在 L4 上進行：L4 是 NVIDIA 的資料中心 GPU，透過 Modal（出租雲端 GPU 的服務）租用。

    - 第 7 章的偵測器短訓練，中途存成 checkpoint（訓練中途的存檔），再讀回續訓，結果和不中斷的訓練一致；見 [GPU／checkpoint 實測](validation/gpu-smoke.md)。
    - 和第 20 章範例同架構的模型，在 L4 上另外訓練 40 步後匯出，交給 TensorRT（NVIDIA 的推論加速工具）執行，和同一張 L4 上的 PyTorch 比對輸出，差異在容許範圍內；見[第 20 章的 L4 實測](lessons/20-deployment.md#l4-results)。第 20 章的 CPU 範例用的是另一份權重，也不經過 TensorRT。
