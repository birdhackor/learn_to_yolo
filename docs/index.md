# 從一個小 CNN，走到你看得懂的 YOLO

我們先用一個小 CNN 回答「整張圖是哪一類」。CNN（Convolutional Neural Network，卷積神經網路）是處理圖片常用的神經網路。再用 ResNet（殘差網路）的捷徑連接，理解網路如何加深：捷徑連接讓輸入走旁路跳過幾層，再加回後面的結果，使很深的網路也比較容易訓練。接著學會同時回答「圖裡有哪些物件，各自在什麼位置」，這種任務叫物件偵測。

YOLO（You Only Look Once，「只看一次」）是一系列物件偵測模型：整張圖只送進網路一次，就同時輸出所有框與類別。本教材的主角是 **MiniYOLO**：為了理解物件偵測而做的小型模型，用 PyTorch（Python 的深度學習函式庫）寫成。沿途每次只引入一個主要變化，看看它解決什麼問題、帶來什麼好處，又增加什麼成本。

**開始前需要會什麼？**

- **必要：**會基本 Python（變數、if／for、函式、list）。
- **有了比較輕鬆：**照著範例跑過一次 PyTorch，聽過神經網路與卷積的概念。第 0 章從一個參數的手算講起，第 1 章說明卷積。
- **數學：**高中程度的函數、對數、向量與矩陣乘法即可。導數（變化率）與連鎖律，第 0 章會用數字例子從頭說明。

## 這裡怎麼學

從第一節（第 0 章的暖身）依序讀：**超短暖身 → 小 CNN → ResNet → 單張圖片的物件偵測 → YOLO 的演化 → 影片與部署**。部署是把訓練好的模型匯出，交給其他程式或裝置實際使用。已有基礎時，可先看[完整閱讀路線](learning-path.md)，再看各節開頭寫的前置，決定從哪一節開始。

讀完第 0–8 章，你會一步步走過物件偵測的完整流程：把人事先標好的答案轉成模型要學的數值，再訓練模型、用它預測新圖片、檢查它找對多少，最後接上自己的圖片與資料。第 9–16 章再用小實驗，逐一看 YOLO 各版本的機制想解決什麼問題。這些模型能做到哪裡、還不能做什麼，見下方〈這份教材目前驗證到哪裡〉。

## 先看一個偵測的小問題

假設圖片裡有一個物件（這裡用紅色矩形代表），我們事先用框標出它的位置。這種事先由人標好的正確答案叫「標註」；下圖的紅框是標註，不是模型的預測。

一張圖可能有好幾個物件，所以模型不只輸出一個框。第 7 章的簡化模型把圖片切成 4×4 個格子，每一格各輸出一組數字（這裡有沒有物件、框在哪、是哪一類），共 16 組；每一組對應一個「輸出位置」。訓練時要先決定哪個輸出位置要學這個框；沒有分到框的位置，則學「這裡沒有物件」。第 7 章的規則是讓**物件中心所在的格子負責預測**。先用下面的示意圖看懂這個規則。

![64×64 圖片中，紅框左上角為 (8,12)、右下角為 (24,28)，中心黑點 (16,20) 落在藍色的第 2 列、第 2 欄格子](assets/diagrams/object-journey.svg){ width="400" }

座標寫成 `(x,y)`，從圖片左上角 `(0,0)` 開始，x 向右、y 向下，單位是畫素（pixel）。紅框的中心是左上角與右下角的平均：x=(8+24)÷2=16，y=(12+28)÷2=20，也就是 `(16,20)`。圖片寬、高都是 64，切成 4×4 格，每格寬、高就是 64÷4=16 畫素。要找中心落在哪一格，就把座標除以 16，再捨去小數：

- 欄（直的一排）看 x：16÷16=1。
- 列（橫的一排）看 y：20÷16=1.25，捨去小數得 1。

所以中心落在**第 2 列、第 2 欄**，就是圖中藍色虛線的格子；程式從 0 起算的索引是 `(列=1,欄=1)`。注意索引先寫列（由 y 決定）、再寫欄（由 x 決定），順序和座標 `(x,y)` 相反。例如中心若在 `(40,20)`，40÷16=2.5、20÷16=1.25，捨去小數後索引是 `(列=1,欄=2)`。

中心的 x 恰好在分界線 16 上，圖中的黑點就壓在這條線上。照「除以 16 再捨去小數」，16÷16 剛好是 1，所以它歸欄 1，也就是右側那一格（欄 1 涵蓋 16≤x<32）。同理，y 剛好壓在橫線上時，會歸下方那一格。框本身可以跨過幾個格子（這個框就跨了 4 格），負責格子仍由中心決定。

不必現在記住這組座標。之後的[訓練目標（target）](lessons/07-targets.md)會用同一個例子，逐步把標註轉成模型要學的數值。

偵測還有三件需要分清楚的事，後面會分節實作：

1. **訓練：**把圖片交給模型，用已知的標註計算預測誤差（loss），再更新參數，讓模型學會找物件。
2. **推論：**把新圖片交給訓練好的模型，取得預測框與類別；這時不需要答案（標註）。每一格都會輸出一個框，分數太低的先丟掉；旁邊的格子也可能對同一個物件給出很像的框。所以最後用 NMS（Non-Maximum Suppression，非極大值抑制）整理：在同一類的框裡，留下分數最高的那個，刪掉和它重疊超過門檻的其他框；剩下的框再重複這個步驟。
3. **評估：**用有標註、未參與訓練的圖片，對照預測與答案，檢查模型找對了多少。這時不更新參數。一定要用沒參與訓練的圖片，是因為模型可能只是記住了訓練圖片的答案；換成它沒看過的圖片，才知道它是不是真的學會。

有了這條基本管線（從輸入圖片、訓練、推論到評估，接好的一整串步驟）之後，再逐步研究各個 YOLO 系列怎麼改進這條管線，從早期版本一路到 YOLOv12、YOLO26。每一節都會說明借用了哪個機制、做了哪些簡化。YOLO 由不同團隊發展，名稱裡的數字由各團隊各自命名，不是同一個團隊依序推出的編號；版本號也不等於適合所有任務的排名。

## 這份教材目前驗證到哪裡

- **電腦需求：**核心練習用 CPU 就能執行，不用下載大型資料。影片與部署章另有工具需求，各節會列出。
- **驗證方式：**你會先用已知答案的小例子檢查座標、框與計算，再用 CPU 確認模型能產生預測、計算誤差、更新參數。
- **已確認：**短訓練顯示，在程式畫出的幾何圖形這種刻意簡化的題目上，小模型學得會。
- **做不到：**這些模型不會直接認得照片裡的貓或車；想偵測真實物件，要用自己標註的資料重新訓練（第 8 章示範資料格式與流程）。
- **還沒確認：**這樣重新訓練後，在真實照片上的辨識效果仍待實驗；用真實資料長時間訓練，以及不同架構的完整品質／效能對照，也還待安排。
