# 審閱穩定性實驗結果

這次沒有證明新增概念清單與第二位核證者能減少必要缺漏的漏報。A、B、C 都命中全部 12 次必要缺漏測試；C 減少了少數額外誤報，但付出較多紀錄與核對工作。教材與 SKILL 均未修改。

## 做了什麼

保留原有四題，比較三種流程：

- A：一名讀者依現行 SKILL 審閱。
- B：兩名讀者各自依相同標準審閱，合併具體問題。
- C：首位讀者回答相同四題，另記重要概念與未知內容；第二位先獨立讀來源、凍結自己的判斷，再核對首位讀者的答案。

測試材料是 CSP、NMS、AP50、DFL 各四種短篇版本（完整、必要缺漏、僅英文全名缺漏、合理延後），加上原始 DINO 22.1，共 17 份。每份重複三輪，每組 51 筆最終判斷。五種閱讀角色共使用 60 個全新 AI 上下文，產生 255 筆個別判斷；B 的合併結果是衍生資料。必要缺漏只有四種，各重讀三次，不能當成 12 種獨立缺漏。

讀者逐段閱讀並記錄首次使用時的判斷；評分者拿到匿名結果、來源與事先凍結的案例標準。共同讀者指令還要求逐字來源及當下使用檢查，因此 A 也不是只隨口回答四題的弱基準。

## 結果

| 指標 | A | B | C 首讀者 | C 最終核證 |
| --- | ---: | ---: | ---: | ---: |
| 必要缺漏命中 | 12/12 | 12/12 | 12/12 | 12/12 |
| 該角色在首次需要時命中 | 9/12 | 10/12 | 11/12 | 9/12 |
| 完整／合理延後版本的必要誤報 | 0/24 | 1/24 | 0/24 | 0/24 |
| 全部案例含額外必要誤報的次數 | 2/51 | 1/51 | 1/51 | 0/51 |
| 名稱缺漏以 optional 正確指出 | 15/15 | 15/15 | 15/15 | 15/15 |
| 未能判定 | 0 | 0 | 0 | 0 |

「額外必要誤報」可與正確命中同時出現。例如 C 首讀者抓到 AP50 匹配門檻缺漏，同時保留了後文已解決的 precision／recall 誤報；核證者撤回後者。C 沒有補到任何首讀者漏掉的必要缺項，也沒有丟掉最終必要命中。

及時命中衡量各角色自己的閱讀時間線。C 最終核證者先獨立閱讀來源，因此 11/12 與 9/12 不能直接解讀成整個 C 流程把偵測延後。它仍顯示一項風險：核證者可能不認同首讀者的合理早期報告。CSP 在 u1 已有概念介紹負擔；部分核證者把首讀者的這項未知當成可以延後，直到 u2 才指出路徑缺漏。增加審閱者本身不能保證保留有效的首次介紹問題。

## DINO 的判讀界線

原始 DINO 22.1 三輪各組均指出英文全名缺漏。啟動讀者前，兩位獨立來源裁定者共同判斷：該頁提供了足以支撐「生成不同視角」這節的基本角色與機制，英文全名及其含義缺漏屬 optional；第三位來源核對者也支持此分類。原作者較嚴格的期待保留在證據中。

部分角色與目的散在不同敘述中，需要拼接理解；此分類不表示文章已有一句清楚、完整的定義，也不否定應該提早明寫的教材需求。這個 DINO 案例不能用來證明流程能抓到「完全沒交代方法目的」的必要缺漏。

## 代價與限制

C 的序列化紀錄為 2,433,657 字元，約 B 的 2.74 倍、A 的 5.31 倍。這包含程式複製的文字，不是生成 token、計算費用或人類工時。逐段保存、兩層核對、盲評與最後抽查讓本次小實驗擴大成過長的流程；這次不再增加試驗，也不據此改寫 SKILL。

所有案例是同一本教材的短篇改編，重複使用同類 AI；共同檔案的隔離靠指令與申報，並非安全沙盒。結果不能推成整本長教材、跨領域或真實初學者都不會漏報。各組最終必要命中均滿分，使本次測試無法區分漏報改善；少量誤報差異也不足以證明 C 穩定優於 B。

欄位完整不等於內容完整：概念清單可能仍漏列未知，核證者也可能錯判「可以延後」。保留四題與具體來源／首次使用檢查較有依據；全面新增第二位逐項核證者的效益在本次未獲支持。
