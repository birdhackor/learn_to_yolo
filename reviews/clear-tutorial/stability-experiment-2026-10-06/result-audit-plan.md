# 結果核對補充方案

本檔在讀者尚未全部完成、匿名判分尚未開始前保存。它補充 protocol 所列的獨立結果核對，不改 gold、主要分數或閱讀指引。

由全新上下文的核對者检查全部 freeze hashes、逐段時序、C 主張索引覆蓋、判分 ID 覆蓋、組別合併及分母。共享檔案系統隔離只靠指示與申報；時序檢查不能證明未曾讀過其他檔案。

語義抽核先用固定字串 `result-audit-2026100604` 與 evaluation_id 的 SHA256 排序：每個必要缺漏 case／role 選三次重讀中的一筆（4×5=20筆），另從 none 與 optional 各選5筆。再納入全部必要漏報、分級不符、必要誤報、undetermined 或 record_concerns 非空的紀錄。這個選擇規則在看到判分前固定；抽核不代表重判全部255筆。

另按相同固定排序，每個 C 核證上下文抽4條核心 claim，並納入全部 supported=false 與 reader_disposition_valid=false 的核證項。這只核對部分核證語義，不把索引齊全當成所有引用皆正確。教材缺漏、讀者紀錄缺陷及流程未完成分開處理。

抽核封包保留匿名 evaluation_id、來源、gold、原判斷與原分数；統計核對另需讀身份映射，但不得因此改 gold 或原判分。核對者的分歧另存並報告敏感度，不能靜默覆寫原讀者紀錄或挑掉不利結果。若發現程式計數錯誤，可修正程式並保留原因與前後結果。
