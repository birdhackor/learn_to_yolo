# clear-tutorial：YOLO 專案版

使用入口是 [SKILL.md](SKILL.md)。YOLO 補充規則已直接整合進主入口，不需另讀這份 README 才能取得：

- 依使用者本輪指定與已公布閱讀路線設定背景；未另指定時只假定基本 Python（含 class）與閱讀路線列出的高中數學，PyTorch、NN／CNN 經驗不作入門節省略教學的理由。
- 寫作前列必要概念、首次使用處、實際已教先備、解釋位置與學習結果；按依賴安排，辨認尚未命名的核心方法。
- 全書入口建立問題背景、必要歷史與階段動機，明確銜接簡化例子和一般方法；交代資料、任務、模型、維度、表示與 loss 的轉換理由。
- NN 連起加權加總、非線性與多層組合，訓練定位梯度下降法；CNN 區分空間尺寸與通道權重，分類連起 logits、softmax、交叉熵與 loss 選擇。
- 方法理由連到具體任務：能力限制、新機制與用途可由圖、數字或推理核對；計算便利等其他理由據實說明。「增加表達能力」或數學性質不能單獨當成理由完整。
- 限定與例外回應當下疑問，先把主敘述寫準確；技術正確但用途或位置不當也要處理，必要限定仍留在需要處。主入口直接提供正確、教學不足與技術錯誤的對照例子。
- 以只讀主文能否理解下一步判斷選讀分界；必要直覺、算例與圖解置於首次需要處，不把前文選讀當成所有順序讀者的先備。
- 對齊圖片、框、張量、座標與單位，核對圖、圖說及實際 Zensical 頁面。
- 以起點、問題、改動、理由、收益與代價講版本演進，區分簡化示範與控制比較。
- 說明偵測指標與訓練證據的含義，不把 loss 下降或小型 GPU 測試當成泛化或正式效能。
- 先逐段提供正文並保存當場理解，再補讀選讀；分輪查技術、銜接及實際圖文位置、折疊、跳轉與累積負擔，保留原始問題及修正後複查。
- 每個必要新概念首次使用時分別作四題檢查，小節末再檢查整體關係；逐項留下引文，區分明說、前文已教、推得與未知。
- 四題附重要新方法的原句對照，分開核對方法身分、目的與本節步驟的關係；需要拼接的必要介紹具體報出，後文釐清仍保留早期問題，不增加題目。
- 第二題核對理由的因果連結與具體用途；限定句核對當下疑問、先備與位置。小變化測試要能看出讀者理解理由，不能只復述術語；對應例子與預期答案不提前附給首次閱讀者。
- 新名稱在首次正文教學時交代名稱與必要含義；必要介紹的未知具體報出，後文澄清不改寫早期判斷。名稱補充與主要理解障礙分開評級，一般概念不強求訓練成果。
- 小變化測試檢查理解理由與常見誤解，保存預測與依據；正文首讀後再核對概念覆蓋，補查來源如實記錄，不提前提供作者清單或答案。
- 必要解釋／圖缺漏，或需猜測、拼湊、回讀補洞，即使列為增加理解負擔也待修，不判首次閱讀通過；可保留改善逐項說明理由。
