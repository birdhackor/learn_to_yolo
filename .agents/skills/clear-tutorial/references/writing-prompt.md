# 可直接貼用的寫作 prompt

依 [SKILL.md](../SKILL.md) 與使用者本輪的階段、範圍及讀者背景撰寫教材。先列必要概念、首次需要處、實際已教先備、解釋位置及學習結果；按依賴安排，辨認操作背後尚未命名的方法。規劃不必放入學生正文，也不提前交給首次閱讀者。

入口用簡短問題背景與必要歷史建立大局觀，再接階段動機。每小節聚焦一個主要學習問題；先展示可理解的材料、任務與答案，再引入表示、公式與程式。沿用例子；換資料、任務、模型、維度、表示或評分方式時，說清楚理由與保留的關係。簡化例子明確連回一般方法。

必要新概念首次用於機制、推理或使用規則前，交代名稱、當下意義、角色、前文關係與理由，接住已讀材料最容易引出的疑問與混淆。重要縮寫展開並解釋，完整名稱不能代替概念介紹；尚未需要的內部推導可待教。

方法理由連起目前需要、原做法需處理的工作、新設計改變什麼及為何有幫助。可能是突破限制，也可能是改變表示、拆分工作、利用已有結構或降低成本；據實說明，不虛構舊方法無法完成。運算形式與概括好處不能單獨代替設計用意。

先確定例子要教操作、共同規則、設計差異還是支持效果，再檢查材料是否足夠。要呈現模式或優勢時，提供足夠變化、對照、圖解或推理，指出保持的關係及其用途；不要求每個例子都用兩組數字。會算結果不等於理解方法理由。明確假設的數字可示意機制，不要求實測來源；宣稱效果時才提供相應證據。

比較公平描述新舊做法各處理什麼，不把原方法說成只能記個別答案。說明便利的來源、條件及必要代價，分開結構改變、可表示、成功學習與泛化。限定回應當下疑問，先把主敘述寫準確，保留解讀結果必需的限制。

以只讀主文能否理解概念、圖、理由與下一步判斷選讀分界。必要直覺、算例與圖解放在首次需要處且相鄰；完整推導、變體與重做紀錄可補充。圖、文字、數字與程式一致，實際桌面與手機頁面合理可讀。一般概念不強求訓練產物，不因文句問題啟動全套實驗。

審閱依 [review-protocol.md](review-protocol.md) 逐段保存正文首讀，再查技術、銜接與版面。每個必要概念首次使用及小節末答四題：是什麼、為何教及如何改變問題、如何用、例子呈現與支持什麼。逐項附當下已讀依據；重要方法另核對身分、設計理由與當前例子的關係。小變化檢查預測與理由，不只換數字套公式。

通用判準與專案技術參考分開；主入口及本 prompt 不放待審教材的改寫答案。首次閱讀者不取得同款示範、作者結論、舊問題清單或技術答案。先保存新判斷，再比對舊問題；允許新發現、漏項、舊問題不成立或重新分級，不以命中答案表作唯一驗收。

必要理解仍需猜測、拼湊或回讀補洞，具體列待修；後文釐清追加位置，不改早期紀錄。保留已教部分，不誇大缺漏。未做檢查不宣稱通過，更新 skill 不代表已改教材或重新驗收。
