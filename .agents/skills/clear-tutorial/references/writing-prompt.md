# 可直接貼用的寫作 prompt

請依 [SKILL.md](../SKILL.md)、使用者本輪指定及已公布閱讀路線撰寫教材。未另指定時，只假定基本 Python（含 class）與閱讀路線列出的高中數學；PyTorch、NN／CNN 經驗是較有幫助，不是可省略入門教學的條件。先列必要概念、首次使用處、先備及實際已教位置、本文解釋處和學習結果，按依賴安排順序；辨認操作背後尚未命名的核心方法，不只清點名詞。概念安排可與規劃合併，不必放進學生正文。

全書入口用簡短問題背景與必要歷史建立大局觀，再說明階段學習的理由；影像路線可由辨識的困難與 ImageNet／AlexNet 的轉折，連到整圖分類、定位、多物件與即時偵測。故事核對來源，不把 CNN 說成 2012 年才出現，也不把分類說成圖裡只能有一個物件。不要求每節重講歷史。每小節聚焦一個問題，先用具體例子說清楚任務、輸入與答案，再引入張量與公式，說明各軸、座標、單位與圖片空間。沿用例子；換任務、模型、維度、表示或 loss 時，交代理由與保留的關係；把簡化例子明確連回一般方法。

必要新概念或方法首次用於機制、推理、使用規則或實作前，介紹名稱（重要縮寫給完整名稱與中文意義）、角色、與前文的關係、理由及當下所需含義，並接住例子最容易引出的混淆。NN 入門連起加權加總、bias、線性／仿射運算、非線性與多層組合；訓練示範把 loss、梯度、學習率和重複更新連回梯度下降法，再定位 SGD。CNN 單通道到 RGB 先解釋空間尺寸與通道深度，區分跨位置共用與跨通道權重；MSE 到交叉熵說明答案性質和選擇理由，先介紹 logits／softmax／交叉熵的關係，再給函式使用規則。不要把其他設計說成數學上不可能，不要求當場教所有變體或完整推導。

方法用來突破能力限制時，連起原本能做什麼、具體情況下做不到什麼、新設計如何增加能力，以及對當前任務的用途。用圖、數字或推理展示；「增加表達能力」或「多層乘加可合併」不能單獨代替非線性在分類中的理由。若目的是計算便利或統一表示，據實解釋，不硬編舊法完全做不到。限定與例外須回應當下疑問或防止具體誤解，先把主敘述寫準確；技術正確但引入尚不需要的概念也可能打斷主線。必要限定仍留在需要處。正誤例見 [SKILL.md](../SKILL.md#方法理由要連到具體問題)，用於學判準，不是固定模板或教材已驗收的證據。

用「只讀主文」判斷選讀分界：不開選讀或外部解釋，依已讀必要前文仍能理解概念、圖與下一步推理，才可把那些內容留作補充。必要直覺、算例與圖解放在首次需要處並與文字相鄰；不以難度決定是否選讀，也不一律把選讀搬回主文。安裝、完整參數、進階推導與重做紀錄可補充。涉及訓練才分清材料、參數更新、成果與使用時輸入輸出；一般概念不強求訓練成果，沒有比較主張也不要求證明較好。

YOLO 演化說清楚起點、改動、理由、收益與代價；分開機制示範、完整訓練與公平比較，分清論文主張、實測與推論。圖、圖說、程式與數字一致，靜態和手機頁面也能讀懂；loss 下降不等於泛化。正文保留必要設計、結果解讀與能教會概念的失敗案例。

審閱先逐段讀正文，每個必要新概念首次使用時分別回答 [SKILL.md 的四題](../SKILL.md#主要概念的四題檢查)，小節末再檢查整體：是什麼與前文關係、為何教、如何使用與結果用途、例子支持什麼。每個核心主張附當下已讀引文，分清正文明說、前文已教、推得與未知；每個重要新方法另附身分／目的／當前步驟關係的原句對照與判定。能操作或引用一句話不足以證明理解；「不用親自操作」也不能讓已用來解釋規則的概念延後基本介紹。必要介紹需靠拼湊，就具體列問題；正常依已教知識推導不算缺漏。後文釐清追加位置，不回寫早期判斷。

第二題核對理由是否完整：能力限制、具體情況、新機制與任務用途是否由當下正文接起；只有概括好處仍列需補說明。對用途不清的限定句，核對它所回應的疑問、所需先備與當前位置的必要性，不因技術正確就接受。小變化要對準理由，例如在同一個不可直線分隔的例子中拿掉非線性、只增加乘加層，請讀者說明是否能解決問題及原因；只復述「需要非線性」不足。首次閱讀包不附本節對應的示範或預期答案；提前看過相同例子及答案的提示限制如實記錄。

每個主要例子用已教範圍的小變化檢查理解理由或常見誤解，保存預測、理由及依據，不只換數字套公式。先完成本輪範圍的正文路線並保存當場判斷，才補讀選讀並分開記錄新增理解；已補讀者繼續後續正文時，不改稱純正文首讀。協調者於正文首讀後核對概念覆蓋，概念安排與作者答案不提前給讀者；漏項補查如實標明來源。再分輪查技術、前後銜接與實際圖文位置、折疊、跳轉及累積閱讀負擔。必要解釋／圖缺漏，或仍需猜測、拼湊、回讀補洞，即使屬增加理解負擔也列待修，不判首次閱讀通過。可保留改善列理由；未做的檢查不宣稱通過。遵守本輪工作範圍，更新 skill 不等於已改教材或重新驗收。
