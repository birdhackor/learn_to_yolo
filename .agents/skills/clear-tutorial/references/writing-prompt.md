# 可直接貼用的寫作 prompt

請依 [SKILL.md](../SKILL.md) 為有基本 Python／PyTorch、NN／CNN 理解、大學數學學過但未必熟練的讀者撰寫教材，也維持閱讀路線已公布的較低門檻。每小節聚焦一個問題，先用具體例子說清楚任務、輸入與答案；涉及圖片偵測時展示圖片、框與真值的對應，再引入張量與公式，說明各軸、座標順序、單位和目前使用的圖片空間。沿用例子，術語在需要時解釋，讓問題、操作、可見結果與原因連成理解路徑。

YOLO 演化說清楚起點、改動、理由、收益與代價；分開機制示範、完整模型訓練與公平比較，分清論文主張、本專案實測與推論。圖、圖說、程式與數字必須一致，靜態和手機頁面也能讀懂；訓練 loss 下降不等於泛化。安裝、完整參數與重做紀錄放補充區，正文保留必要設計與能教會概念的失敗案例。

重要新概念或命名方法第一次進入正文教學時，介紹名稱（重要縮寫給完整名稱與中文意義）、角色、與前文的關係、學習理由及當下所需含義；不能只教上位類別或小操作。涉及訓練才分清訓練材料、訓練後成果與使用時的輸入輸出；一般概念不強求訓練成果，沒有比較主張也不要求證明較好。

審閱逐段揭露並在開放後文前保存當場理解。在主要概念首次用於解釋機制、推理或實作時，以及小節末，回答 [SKILL.md 的四題](../SKILL.md#主要概念的四題檢查)：是什麼與前文如何銜接、為何教、如何使用與結果用途、例子或推導支持什麼。每個核心主張附當下已讀引文，分清正文明說、前文已教、推得與未知；必要介紹仍未知就列為具體問題，後文澄清不回寫早期判斷。名稱補充與主要理解障礙分開評級，再分輪查技術與銜接；未做的檢查不能宣稱通過。遵守本輪工作範圍。

四題另附每個重要新方法的原句對照：方法身分與整體角色、方法目的、本節步驟與方法的關係；每項記原句與位置、來源狀態、當下判定與理由。這是證據欄，不增加題目。若必要介紹仍需靠導覽、上位類別或小操作拼接，指出缺的連結並列為理解負擔，不能只標「推得」就判介紹完整。承認前文已完整教過的內容，正常推導不算缺漏，內部細節可合理待教。後文釐清追加位置，早期介紹／時序問題仍保留在報告中。
