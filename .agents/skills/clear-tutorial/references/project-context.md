## 需要時核對的技術事實

以下不是每節必教的清單，也不指定例子或段落寫法。依當前主張核對；不確定時回查原論文、官方文件與目前實作，保存支持位置。

### 歷史、方法與任務

- CNN 早於 2012 年；ImageNet 與 AlexNet 的歷史應區分資料集建立、競賽結果、模型及運算條件，不將突破歸因於單一因素。
- 整圖分類描述任務要求的輸出，不表示輸入圖只能有一個物件，也不限制基礎架構只能用於分類。YOLO 不是第一個物件偵測方法。
- 經典感知機的硬閾值與現代網路的啟動函數、訓練方式有差異；勿以同一名稱混用。
- 含非零偏移的 Wx+b 是仿射映射；無偏移時是線性映射。僅由仿射層組合仍為仿射；含非線性機制時則需按實際函數分析。分類邊界還依輸入表示與判定規則，不能把特定條件擴大為所有分類方法。

### 卷積、表示與損失

- 卷積的空間尺寸與通道深度分開核對。標準 groups=1 卷積中，各輸出濾鏡對各輸入通道有相應權重，再合成輸出；跨位置共用與跨通道綁定是不同約束。後者可形成另一種設計，不是數學上不可能。
- 感受野、stride、padding、輸出尺寸與參數量依目前網路設定查核；圖、公式與程式須對應，不能把進階變體的公式套在不同設定。
- 類別編號通常表示類別位置，不表示量值距離。MSE 並非絕對不能用於分類，損失選擇應按答案表示與任務核對。
- logits 是類別分數；softmax 將其轉成類別機率。PyTorch cross_entropy 接 logits，內部用數值穩定的 log-softmax 等計算，不先手動 softmax；函式用法、機率含義與完整推導分開核對。

### 座標、指標與版本

- 座標與張量核對軸、順序、單位及圖片空間，包括原圖、resize／padding 後圖片與特徵圖。圖片、答案、損失與解碼使用一致約定。
- 分類正確率、IoU、AP50 與 mAP50–95 不同；AP 還依真值配對、IoU 門檻、precision／recall、插值及類別平均設定。合成資料分數不能直接類比 COCO 成績。
- 區分原論文、官方實作、本專案實測與機制推論。不同團隊的 YOLO 命名不自動構成同一條官方演化線；簡化模型不自動重現原網路或完整方法。
- 版本比較核對資料、模型、候選數、損失權重、參數量與更新步數等差異；不同小示範的分數不能單獨支持版本優劣。

### 執行與證據

- 訓練主張核對真正更新的參數、必要的梯度與權重變化。只做 backward 而未更新參數，不是模型已學會的證據；有參數更新也不單獨證明已學到所宣稱的能力。
- 實際觀察梯度時按主張與模型解讀，不把每個參數必須非零當成所有步驟都成立的條件。固定小資料的 loss 下降支持該例子的優化，不支持泛化。
- 資料來源、切分、device、步數與學習率依主張查核。小型 GPU 檢查可驗證流程，不自動構成正式效能評測。
- 計時核對同步、前後處理、記錄、存檔、啟動與傳輸是否包含；不同計時範圍不可直接比較。
- 正文疑點先查指定版本來源與既有證據，只做相稱的執行檢查；不因教學文句修改啟動全套 GPU 訓練。
