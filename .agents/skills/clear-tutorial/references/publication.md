# 審閱保存與教材發布

審閱幫助改善教學，建置核對目前要交付的內容。依改動範圍安排易讀性、正確性與連貫性檢查；修正後複查受影響單位與必要過渡。既有獨立觀察保留原判斷與時點，但小修不要求重新重放所有歷史輪次。

## 保存依用途決定

- PR 簡述改動、審閱範圍、具體發現、修正、驗證與未驗證事項。逐段閱讀、派工、凍結原稿與截圖可用短期 artifact，無須全部提交。
- 支持科學或教學事實的必要來源、授權、資料切分、配方、重要結果與限制長期可查。移走原檔時修復引用，使用固定版本與可核對的取得方式。
- 正文、程式與公開執行入口保存在適合維護及讀者取得的位置。生成檔是否留在 Git 依實際用途決定，例如固定版本的公開 Notebook。
- 大型資料與模型明確按需下載；保存固定版本、大小、SHA-256、授權與重建資訊。替代資產先發布並以乾淨下載核對，再移除原路徑；不覆寫本機修改或既有發布。

## 發布核對目前內容

- 來源同步、有效執行結果、嚴格建置與連結／下載檢查依專案要求執行。歷史審閱 session、舊稿指紋或原審閱者回叫不作部署依賴。
- 重用執行結果時核對有序程式、共用程式、實際資料與環境；真正被程式讀取的 Markdown 也算輸入。缺少、過期、失敗或無法確認的結果必須重新執行。文字更新使用目前文字，保留結果真正的執行版本與日期。
- 建站、互動、測試、資料重建與訓練各裝需要的依賴。選用資產不存在也能完成一般閱讀路線；測試與教材程式不暗中連網下載。
- 實際核對已部署版本及公開入口。建置成功、檔案取得成功、實驗可執行、能力成立與讀者理解分開陳述；相同檔案不代表結論已獲驗證。

這些是通用維護準則，具體工具、保存期限與發布版本規則由專案參考決定；採納合理機制不以量化收益或另建一套審閱系統為前提。
