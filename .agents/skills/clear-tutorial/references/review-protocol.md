# 依閱讀順序審閱教材

## 目的與範圍

熟悉技術的人可以讀完整節後重建作者意圖，仍可能漏掉初學者在中途需要的說明。術語有定義、算例正確、程式能跑與圖檔存在，都不能單獨證明首次閱讀順暢。

依 [SKILL.md](../SKILL.md) 保存「第一次讀到這裡的理解」，再開放後文。使用者只要求審閱時，核對凍結稿而不修改；已授權修正時，再另存修後複查，不用後文或修正答案改寫早期紀錄。

## 審閱前準備

1. 指定工作範圍、目標讀者、必要先備及實際閱讀路線。不把較有幫助的經驗當成必要背景，不默默提高入口門檻。
2. 凍結版本，保存來源與圖的指紋、正文／選讀分界及必要前文。按有意義的單位拆開，不截斷一句或拆散必要圖說；保留圖的原位置與折疊狀態。
3. 協調者保留全文及概念安排。首次閱讀者每次只取得當前正文單位和已讀前文，不提前取得選讀以補洞，也不取得作者目標摘要、概念清單、舊問題、同款正誤例、技術答案或預期結論。
4. 保留必要圖在原稿中的位置；不能把頁尾圖提早搬進閱讀包，讓缺圖問題消失。圖本就相鄰時，與說明一起提供。
5. 每個必要新概念首次用於機制、推理、規則或實作時設檢查點，小節末再檢查整體；同一單位多個必要概念分別記理解，不以流程的一份答案涵蓋全部。
6. 協調者按依賴建立概念安排，包含未命名的核心方法、表示轉換及階段動機。清單不提前交讀者；正文首讀完成後才核對覆蓋。
7. 若已授權獨立審閱，各類審閱由不同審閱者負責，技術與銜接審閱者不參與撰寫。使用 subagent 時，首次閱讀者從無作者歷史的上下文開始，提供通用判準、讀者背景及當前閱讀包，要求不搜尋未讀內容或外部解答。共用檔案系統不是真正隔離；提前看過全文或對應答案者記錄影響，不聲稱未提示首讀。沒有獨立審閱者則標作者自查。

順序讀者可使用實際已教的必要前文，不把名稱出現當成機制已教。選讀不自動算先備；跳讀路線另開紀錄，明列必要背景。局部審閱沒有首次使用處的紀錄，就不宣稱驗證過介紹時序。

## 第一輪：逐段正文首讀

取得下一段前，用自己的話保存：

- 現在在做什麼，為什麼要做。
- 輸入、答案、編號、符號、圖中元素與箭頭代表什麼。
- 下一步預期改變什麼，當下有哪些原句或圖支持。
- 哪裡需要猜測、回讀、跳轉或課外知識；引用位置與原文。
- 尚未看見卻需要理解的素材、對應或圖解。
- 我能解釋設計用意與相關概念的差別，還是只能操作。
- 更換材料、任務、表示、維度、模型或評分方式的理由，及簡化例子與一般方法的關係。

閱讀程式前確認它要實現什麼、這段是操作示意、梯度檢查、參數更新或評測；程式後確認輸出意義及可支持的結論，不只復述形狀。

作者先提問、隨即解答是合理安排，不要求讀者未學先知。概念已被拿來推理或解釋規則而必要意義仍不清楚時，才具體列缺口。後文釐清追加位置，保留當時判斷。

### 先讀正文，再補選讀

完成本輪整段正文路線並保存判斷後，才補讀選讀、附錄或外部解釋，另記新增理解與是否應放回首次需要處。連結存在不等於說明已讀；必要圖在正文缺席時報出，不由協調者悄悄補上。

主文可用明確列為必要且實際已讀的前文，不以選讀替所有順序讀者補知識。讀者補讀後若繼續後續正文，明記這項先備差異，不能再稱純正文首讀。

### 四題與原句依據

每個必要新概念首次需要時及小節末，各回答：

1. 它是什麼、扮演什麼角色，與前文有什麼關係？
2. 為什麼在這裡教它？它回應什麼問題、如何改變需要處理的工作或增加能力？
3. 如何使用？需要什麼、得到什麼及結果供後續如何使用？
4. 例子、圖表或推導呈現什麼關係，支持什麼理解或結論，哪些還不能推出？

說明回答的對象；子步驟與上位類別不能代替方法總覽，多個概念分開記理解。一般概念不強求訓練產物，未宣稱效果比較時不要求全面優劣實驗。

每個核心主張引用當下已讀原文或圖中具體依據，分別標：

- 正文明說：目前正文直接支持。
- 導覽／前文已教：引用實際已讀位置，按內容記錄，不誇稱導覽已完整教機制。
- 由已讀內容推得：列支持句與推論關係，不靠專家常識補答案。
- 目前不知道：說明缺什麼及現在是否已需要。

重要新方法另附三項對照，可引用四題的證據，不新增題目：

    方法名稱／閱讀單位／已讀範圍：
    身分與整體角色：原句／位置／來源狀態／判定與理由／問題編號
    目的與設計理由：原句／位置／來源狀態／判定與理由／問題編號
    當前例子與方法的關係：原句／位置／來源狀態／判定與理由／問題編號

判定用「已足夠／需補說明／合理待教」。相鄰幾句可共同說清楚一件事，不強求固定句型；必要介紹仍須拼湊時列出缺少的連結。正常運用已教知識推理不算缺漏，尚未需要的內部機制可待教，但不能延後基本角色。

保存原始答案：

    小節／閱讀單位／首次需要或小節末：
    當時可見內容及實際已讀範圍：
    正文或補讀選讀路線／可用先備與位置：
    題號／焦點／自己的回答：
    核心主張逐項：主張／來源狀態／位置與引文／推論關係
    未知部分及當下是否需要：
    具體問題與影響（沒有則記無）：
    後來釐清的位置（追加，不改早期判斷）：

### 理由、例子與比較的核對

第二題查「目前需要 → 設計改變 → 為何有幫助」是否由已讀內容成立。理由不限於突破能力限制，也可能是轉換表示、拆分工作、利用已有結構或降低成本。涉及分工時，查明哪些已有部分被保留或直接提供、哪些仍需處理，及此安排如何回應問題；不要求先證明舊法做不到。

第四題另查例子是否足以呈現其教學目的。分開判斷會算結果、看見共同關係、理解設計用意與支持實際效果；其中一項成立不能代替其他必要項。若原文宣稱例子說明優勢，讀者卻只能復述運算，列出缺少的關係及實際影響，不接受概括好處代替解釋。

例子需要呈現模式時，檢查是否有足夠變化、對照、圖解或文字推理及明確指出的共同關係；不以兩組數字作固定門檻。提出缺口時說明「目前目的需要讀者看見什麼，現有材料只能顯示什麼」，而非只要求多加例子。

公平核對新舊方法的角色，不因新設計方便而推定原方法只能記答案或無法利用共同規則。結構的幫助、可能的收益與已驗證效果分開記錄，檢查來源是否說清楚適用條件。

明確假設或手工示意的數字，可解釋機制；只核對一致性與結論邊界，不因沒有實驗來源而報缺。若來源把數字當成實測、學習成果或效果證據，再核對相應紀錄。不把合理簡化的每個數值都追問成實際標籤問題。

對用途不清的限定與例外，查它回應哪個當下疑問、避免什麼誤解及需要什麼先備。技術正確但引入尚不需要的概念，依影響列閱讀負擔；解讀結果必需的限定保留，不一律刪除。

### 小變化與覆蓋查漏

對主要例子的核心關係，以已教範圍內的小變化請讀者預測並說理由；可合併檢查點，不為每個數字另出一題。保存題目、回答、理由、當下依據及暴露的缺口。題目對準因果關係或常見混淆，不只重套公式，也不偷渡未教變體。

題目需要的理由未教時列缺口；先補教再答對，只算修後證據。答對但理由來自課外知識，也不能算正文已教會。

正文首讀完成後，協調者對照概念安排，查必要概念的首次使用、實際先備、解釋位置、未命名方法及轉換理由。補查標明發現者與時點，不算原讀者自行發現，也不把讀過後文的補查改稱盲讀。完整復述可追加，但不能清除閱讀中已保存的斷點。

## 圖與實際頁面

即使沒有圖，也回答讀者是否必須自行想像素材、位置、資料流或答案對應，哪個問題需要圖解，以及文字是否已足夠。已有圖則查它是否呈現當前要教的關係，不能只是一張架構裝飾。

以實際頁面檢查桌面與手機，可採 1280×800 與 390×844 等合理尺寸，保存實際使用的尺寸與畫面。逐段首讀不展示尚未開放內容；整頁與版面檢查另記時點。

核對必要字、線、箭頭、圖說、公式與單位；基本理解不依賴放大，動畫靜止時保留關鍵資訊。檢查第一次需要說明的位置、圖文相鄰關係、折疊、浮動介面遮擋及跳轉。圖存在且字清楚不能代替位置與閱讀路徑檢查；未看實際頁面就標未驗證。

正常複習前文與補當下缺口分開記，再評估多個小斷點的累積負擔。

## 第二輪：技術與證據

首讀紀錄保存後，技術審閱者查專案參考、實作與原始來源：

- 任務、答案、表示、圖與實驗設計是否一致。
- 程式真正做什麼、更新什麼；手算、梯度檢查、參數更新與評測是否混用。
- 數字來源、版本、分母、判準、計時範圍與評估材料是否清楚。
- 比較是否存在重要設定差異、資料洩漏或其他混淆；因果與泛化主張是否有相應證據。
- 淺白敘事是否歪曲舊方法、誇大設計優勢或混淆可能能力與已證明效果。
- 名稱補充、概念缺口、時序負擔、技術錯誤與證據不足是否分開判斷。

逐項核對閱讀問題，保留原文已教部分，只指出仍缺的銜接；不把局部缺項擴大成完全未教。不確定的知識查原論文或官方文件，保存支持位置；只為疑點做相稱執行，不因文句問題重跑全套訓練。

只審凍結稿時保存本輪處置；修改獲授權且完成後，另核對修後版本。不提前把專案技術參考、實作或本輪解答給首次閱讀者。

## 第三輪：銜接與累積負擔

從相關前文讀到本節及範圍內的下一步，確認進入知識與學習結果、新概念依賴、例子到一般方法、表示與評分轉換及術語一致性。先走只讀正文的路線，再檢查選讀分界及實際圖文位置。

若修正改變教學目標或順序，回查受影響的前文與導覽；局部修正重查相關單位、圖與過渡，不盲目重做全書。範圍外的下一章不得自行擴大審閱；可檢查過渡是否交代下一步目的。

## 新判斷與舊問題分開

新一輪獨立審閱開始前，協調者保存已知問題及使用者澄清，不將它們混入通用準則或首次閱讀包。更換 skill 後先凍結該版本，避免途中補入待抓問題的解法。

先保存新的首讀、技術與銜接判斷，再由協調者比對舊紀錄。逐項記重現、新發現、可能漏項、舊問題不成立、來源已變或分級差異及理由。

舊問題清單可幫助查漏，但不是不可推翻的答案表；以來源、實際讀者理解與通用準則裁定。若比對後追加檢查，明標受舊問題提示，不改寫成自行發現。不得用命中數量作唯一驗收，也不得為消除差異事後修改原始首讀紀錄。

## 問題紀錄與通過規則

每項至少保存：

    版本／來源與圖的指紋／小節／閱讀單位：
    當時可見原文與圖／正文、必要前文或選讀：
    原位置、折疊與實際閱讀路線：
    讀者理解及原句依據：
    已教部分／缺少的連結或圖解：
    對主要學習問題的實際影響：
    猜測、回讀、跳轉與累積負擔：
    問題類型／嚴重程度／分級理由：
    發現者與時點／是否受先前問題提示：
    後文釐清／建議修正／處置理由：
    修後版本與實際複查（未做則明記）：

問題類型可用名稱補充、概念介紹、方法理由、例子用途、公平比較、限定用途、先備依賴、轉換、時序、正文與選讀、圖解、閱讀路徑、技術及證據。按影響分級：

- 阻礙主要概念：必要背景不足，主要概念、目的或使用方式無法理解。
- 增加理解負擔：需要猜測、拼湊或回讀才能銜接必要理解。
- 選讀改善：不影響當下主線的名稱補充、延伸或其他可保留細節。

名稱未展開仍記錄，但角色與含義已清楚時不自動升成主要概念阻礙。必要解釋或圖缺漏，即使分級為負擔仍待修；正常複習前文不自動算缺漏。可保留項逐項寫理由，多個斷點累積損害主線時按整體影響處理。

技術正確、能答四題、引文存在或程式能跑，不能單獨代替閱讀證據。方法理由仍缺需要、設計改變與用途的連結，或例子只顯示操作而未呈現所聲稱的教學關係，不判該必要項完整。

保留原始紀錄並追加處置與複查。未做的視覺、執行、獨立閱讀明記未驗證；沒有逐段紀錄的完整頁面審查，不改標首讀盲讀通過。AI 審閱只作輔助，可能時用實際目標讀者回饋調整準則。
