# 跨領域校準：按原問題及作用判證據

例子只示範通用判準；同時接受充分說明、拒絕錯誤放行，不含待審教材答案。

## 排序性質不等於查找理由

一節問「為什麼先把名單排序以加快查找」，只把亂序名單排好，再說「更容易找」。這顯示排序前後不同，尚未解釋如何少看候選。成功條件是找到指定名字或確認不存在，與排序無關；理由須指出如何利用順序縮小候選。清楚的文字即可，不必增加三份名單或完整複雜度證明。

若原問題只教排序操作，排出正確順序便足夠；不能替它硬加查找目的。

## 特例與關鍵作用的範圍

快取保留結果，找不到才重新計算。初始空快取完成一次請求，充分教「沒資料也能得到答案」；不能直接驗收「省下重複計算」，因結果尚未被重用。

正文若說清再次收到相同請求時讀取既存結果、略過那項計算，文字已接起重用理由，不因只畫一次請求就要求第二張圖。特例的充分性與一般用途分開，不禁止空快取例子。

## 任意約定與正常推論

偽 API `make_date(4, 4, 2026)` 不能據此判前兩項是月／日或日／月；兩規則都相容，非對稱日期會影響操作，約定需交代。若來源已有其他不對稱例及明確結果，則先查是否已能唯一推得，不能只看首個對稱例。

已教每頁最多十筆、不足也佔一頁，三十七筆需四頁，是正常推論；留下三滿頁加一不足頁即可，不因沒另寫公式報缺。

路線導覽只需指定任務、基本角色、可靠來源及後續方向，不必在入口證明全部工程成因；當下推算已使用的性質才需教清。
